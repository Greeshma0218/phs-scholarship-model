# PHS Scholarship Model Simulator

An interactive what-if tool for modeling proposed changes to NCF's Presidential
Honors Scholarship (PHS) award structure for FTIC students.

## What it does
Lets you test a proposed model change — a wider GPA/Test stacking window, new
award tables, and a revised PIC award amount — against the actual Fall 2026
FTIC deposited class, and see the projected total PHS spend update live.

## How to use it
Download `phs_scholarship_model_simulator.html` and open it in any browser —
no server or internet connection needed. Every number (award tables, stacking
rule, minimum floor, PIC amount, and the population grid) is editable, so you
can test different scenarios directly.

## Data note
The population grid is currently loaded with the Fall 2026 deposited FTIC
class (n=229, Freshman/Early Admit only, transfers excluded). Figures reflect
a snapshot as of August 2026 and should be refreshed from a new Slate export
for future terms.
